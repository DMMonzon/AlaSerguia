# Instrucciones para la Fuente "29LT Riwaya Informal"

Para utilizar la fuente comercial **29LT Riwaya Informal** en tu sitio web local:

1. Obtén los archivos de la fuente (comprados o descargados de tu proveedor de fuentes oficial).
2. Asegúrate de tener los formatos `.woff2`, `.woff` o `.ttf`.
3. Renombra los archivos de la siguiente manera:
   - Para la versión regular:
     - `29LT-Riwaya-Informal.woff2`
     - `29LT-Riwaya-Informal.woff`
     - `29LT-Riwaya-Informal.ttf`
   - Para la versión negrita/bold (opcional):
     - `29LT-Riwaya-Informal-Bold.woff2`
     - `29LT-Riwaya-Informal-Bold.woff`
     - `29LT-Riwaya-Informal-Bold.ttf`
4. Coloca estos archivos directamente en esta carpeta (`public/fonts/`).

El sistema ya está configurado para cargar estas fuentes automáticamente desde aquí. Mientras tanto, se utilizarán las fuentes de respaldo ("Lora" y "Cormorant Garamond").
